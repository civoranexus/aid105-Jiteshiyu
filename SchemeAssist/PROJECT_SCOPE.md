# SchemeAssist – Project Scope

## What this project DOES
- Allows a user to register and log in
- Collects basic user profile data relevant to schemes
- Recommends government schemes to the user
- Uses an ML model to RANK schemes by relevance
- Shows explanations for each recommendation

## What this project DOES NOT do (Phase 1)
- No admin dashboard
- No scheme creation or editing UI
- No multi-language support
- No document upload or verification
- No real-time updates
- No deployment optimizations

## Completion Definition
The project is considered complete when:
- A new user can register and log in
- The user receives ranked scheme recommendations
- Each recommendation includes a reason
- The system works end-to-end without manual intervention
